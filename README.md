# Free Miner

A free, open-source GPU miner for NVIDIA cards. Mines Autolykos2, Etchash,
Ethash, FishHash, Octopus, NexaPoW, or BeamHash III, and pays out directly
to your own wallet in the coin of your choice (BTC, ETH, LTC, DOGE, SOL,
XMR, ERG) via Unmineable's auto-convert.

**Requires:** an NVIDIA GPU (RTX series recommended) and the NVIDIA driver.

## Developer fee — disclosed
5% of total mining time is automatically redirected to the developer's
wallet to support ongoing development. This is shown live in the app the
whole time it runs — a red fee line at the top, and a "Mining to: ..."
line that switches between your wallet and the developer's. Same model
XMRig and lolMiner use for their own built-in dev fees.

## Realistic expectations
This mines real cryptocurrency, but GPU mining profit depends on your
electricity cost, current coin prices, and network difficulty. For most
people on a single consumer GPU, this is a way to put spare GPU capacity
to use — not a path to significant income. Check current profitability
for your card before expecting much.

## Security note
Antivirus / Windows Defender will likely flag this, because software that
downloads and launches a mining binary matches a common malware pattern,
even when fully disclosed like this one. Full source is in `free_miner.py`
— read it before running it if you want to confirm nothing's hidden.
